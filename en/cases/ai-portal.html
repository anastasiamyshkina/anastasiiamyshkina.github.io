Problem

AI is already in use.

But is it under control?

AI is already widely used — and it brings risks for the company. The AI Portal turns them into value: richer context, control regained and time freed up for teams.

Risks

Risk 01

Leaks into public AI chats

Employees paste confidential data, contracts and client databases into public AI services.

Risk 02

AI is used chaotically

Departments try different tools, but the business can’t see the full picture: risks, cost and real impact.

Risk 03

Routine eats focus

Summaries, status hunting and preparing materials take hours from strong specialists every day.

Value

Value 01

One context from all systems

Knowledge base, documents, CRM and task trackers in one interface, no switching between windows.

Value 02

Scalability

A ready foundation instead of months of integration: add use cases as modules and scale across departments.

Value 03

Expertise for everyone

Policies, templates and best practices built into skills and prompts, so juniors work closer to expert level.

Features

Use cases in the AI Portal interface

Short user stories: what the user does, which product modules are involved and how it’s packaged for implementation.

Documents

PDF / DOCX / XLSX analysis

The user uploads a contract or report. The portal parses it (Tika), summarises it, flags risks and answers questions grounded in document fragments — without sending the file to a public chat.

RAG

Knowledge base search

A natural-language question → semantic search over the wiki and policies (Qdrant + knowledge base MCP). The answer comes with a quote and a link to the source page, respecting access rights.

Skills

Prompts and skills by role

A library of ready-made scenarios for HR, IT, sales and legal: one click runs a typical request with corporate context. Expertise packaged into reusable no-code templates.

MCP

Task tracker and processes

“Status of task X” → MCP to Jira or similar: the ticket, comments, blockers. The model writes a summary and suggests a next step for the stand-up or a manager report.

MCP

Email

Find threads, summarise them, draft a reply. The MCP sees only emails within the user’s OAuth token — the same principle as for CRM and documents.

MCP

Google Docs and Sheets

Find a team document, condense it, suggest edits or a section structure. Integrated via Google Workspace MCP with no copying into external services.

Compliance

Legal

Contract version comparison, a risk checklist, questions for the counterparty. Local or hybrid inference for documents with personal and commercial data.

Each use case is a separate module in the commercial proposal: stack, integrations and KPIs are agreed with the client.

Monetisation model

SaaS, on-premise or consulting

SaaS

  • Quick start with no infrastructure on the client’s side.
  • Access to the AI Portal, base models and knowledge base use cases.
  • Setup: roles, workspaces, first skills.
  • Monthly fee — support, updates, incidents.

On-premise

  • AI Portal deployed in the client’s infrastructure.
  • Local models, RAG, SSO/RBAC and audit.
  • Connecting corporate knowledge, documents and MCP tools.
  • Access policies for models, data and integrations.
  • Training key users and supporting the launch.

Infrastructure requirements

  • Own data centre, colocation or a certified local cloud.
  • Qwen / Llama-class models for sensitive tasks; external models per the security policy.

Consulting

  • Process review: where AI will help and where it won’t.
  • A map of use cases, data sources and systems to connect.
  • Roadmap: roles, KPIs, integrations, stages.
  • Can be an entry point before SaaS or on-premise.

Scope of work and support are agreed per project.
