About meThe prototype was built by a project manager (this demo case). I designed it and filled it with test data to show the UX: calls, reports, assistants, copilot. Product concept: Asterisk + MTS → on-prem STT → core + UI → local LLM; no data leaves the perimeter. Not a commercial proposal and not a real client’s interface.
